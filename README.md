# English Quest — ағылшын тілін ойын арқылы үйрену мобильді қосымшасы

English Quest — ағылшын тілін ойын форматында үйренуге арналған мобильді қосымша. Пайдаланушы тақырыптық тапсырмаларды орындайды, жауаптарына кері байланыс алады және жинаған ұпайын бақылайды. Қосымша ағылшын тілін өз бетінше үйренетін оқушылар мен студенттерге арналған.

## Мақсаты
Ағылшын тілін интерактивті тапсырмалар мен ойын элементтері арқылы меңгеруді жеңілдету.

## Пайдаланушылар
- Оқушы немесе студент
- Контент әкімшісі

## Талаптар
1. Пайдаланушы тіркеліп, жүйеге кіре алады.
2. Пайдаланушы ағылшын тілі тапсырмаларының тақырыбын таңдайды.
3. Жүйе таңдалған тақырып бойынша сұрақтарды көрсетеді.
4. Пайдаланушы сұраққа жауап беріп, оны жібереді.
5. Жүйе жауаптың дұрыстығын тексеріп, нәтижесін көрсетеді.
6. Жүйе дұрыс жауап үшін ұпай есептейді.
7. Жүйе тапсырма нәтижесін деректер базасына сақтайды.
8. Пайдаланушы жеке прогресін көре алады.
